# Ardiles SS27 reference

A searchable, mobile-friendly HTML reference built from the Ardiles Launching SS 2027 presentation. Open `index.html` in a browser. No build step or external dependencies are required.

## Review status

This is a working draft based on text from 168 Canva slides. Twenty-one slides have no extractable text and require visual review. Some source spacing and capitalization require manual cleanup. Chart figures and performance claims should be checked against their source before use. The HTML draft has not been separately approved or browser-tested.
